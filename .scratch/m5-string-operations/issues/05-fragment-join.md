## What to build

Add `string_join(parts: string[], separator: string) -> string` as an immutable builtin. Existing fixed or resizable string arrays provide fragment accumulation; join materializes one immutable result without a mutable builder type or intermediate concatenated strings. Deliver frontend, checked backend, execution and CLI/current-source-browser coverage. Deterministic construction scaling evidence is a separate dependent ticket.

## Acceptance criteria

- [ ] Accept exactly two positional arguments of exact string-array/string types, with ordinary Never compatibility. Supply the existing string[] destination context to empty array literals. Use normal fixed-signature placeholder constraints, not caller-based unification.
- [ ] Support fixed and resizable arrays without requiring resize authority. Emit no new user-visible type, implicit import, builder, production observation control or reclaimable string ownership protocol.
- [ ] Evaluate/capture parts once, then evaluate separator once. Inspect the captured array only after argument evaluation: separator effects may mutate/resize it and are visible; rebinding the source does not redirect it. Invoke no callbacks during sizing/copying.
- [ ] Validate the separator and complete outer array storage before processing entries; structurally validate every consumed string in index order. Validate separator even for zero/one-entry reuse cases. Preserve trusted-host UTF-8 validity/immutability rather than adding full scans.
- [ ] Insert separators only between entries, including empty ones: zero entries and one empty entry yield empty text; two empty entries with comma yield comma; [a,empty,b] with comma yields a,,b. Cover empty/nonempty separators, multibyte UTF-8 and embedded NUL.
- [ ] After required validation, a one-entry join returns the entry and zero-byte results may reuse shared empty text. Other initial M5 results have newly allocated descriptors and copied payloads. Use widened checked sizing before result allocation; retain ABI/allocator limits without arbitrary guest caps.
- [ ] Use sizing/validation then direct final-payload copying, constant auxiliary Wasm locals, and no snapshot collection or intermediate concatenated strings. No mutation of fragments, array contents or separator; no release of published strings.
- [ ] New name is reserved globally and for host-language registration, allows lexical shadowing, and is positional-only, outside direct builtin pipeline stages and default/contract whitelists. Forged typed calls, skipped/unreachable operands, arity/result annotations and planner discovery remain independently checked.
- [ ] Validate emitted Wasm and independently decode helper/layout/control behavior. Execute bounded tests of post-separator mutation/resizing/rebinding, captures, nested effects, alias safety, invalid otherwise-unused operands, trap retention and memory growth/reentry. Preserve absent-M5 bytes/helper order, deterministic output and optimization-preset contracts.
- [ ] Core/CLI/rebuilt-browser bytes and diagnostics agree within each preset, with explicit export selection and host-name coverage. Update language/docs/AGENTS status for join while leaving measurement/integrated acceptance pending. Do not resolve M4's pending performance acceptance.
