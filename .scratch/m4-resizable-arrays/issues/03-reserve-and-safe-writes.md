## What to build

Implement identifier-receiver `values.reserve(additional)` for all three array types, together with relocation-safe ordinary indexed assignments and all five numeric indexed compounds. This is the first source-level payload relocation; it must never land while pending writes can retain stale movable addresses.

## Acceptance criteria

- [ ] Add exactly `identifier.reserve(positional_argument)` syntax without general postfix chaining. Reject parenthesized/call/index-result receivers, named arguments and wrong arity/types. Add a single-dot token without changing ranges or accepting `.5`/`1.`; update grammar. Method names stay contextual identifiers.
- [ ] Capture and validate the receiver/resize authority before argument effects; even fixed-storage `reserve(0)` traps before effects. Evaluate the argument once; revalidate captured current state afterward. Use post-argument length plus additional, accepting finite integral nonnegative values including -0; reject overflow/domain violations before narrowing. Return void; never change length or reduce capacity. No public capacity query/exact capacity promise.
- [ ] Validate exact handle/element/descriptor/capacity/current active payload authority before management mutation. When replacement is needed, acquire full capacity, copy live bytes without scanning unconsumed elements, publish prepared descriptor/private state, then release displaced payload. No callbacks in preparation/publication/release; allocation failure preserves the post-argument published array.
- [ ] For resizable indexed writes: capture handle/index once, validate before RHS; compounds also retain old f64 before RHS. After RHS, revalidate the captured handle/index, resolve current payload and store. Never reread a rebound receiver or reload a compound's old value. Use invocation-local scratch, not persistent pins/host cleanup.
- [ ] Fixed-storage writes keep saved checked-address semantics, including inside mixed M4 modules. Non-M4 programs retain exact bytes and original scratch layout.
- [ ] Prove ordinary/all-five-compound stores across actual RHS relocation and old-buffer reuse, receiver rebinding, captures, host reentry, caught inner traps, pre-RHS failures and completed RHS effects. Cover all three replacement element types. Test no-op and growth reserve plus overflow and failure paths.
- [ ] Update placeholder numeric constraints, pure-whitelist rejection, raw discovery/captures, exhaustive typed traversal and independent forged-tree checking. Unreachable/skipped syntax is checked and discovered; preserve Never and preset parity.
