## What to build

Produce reproducible M4 append/reserve/remove growth, reuse, timing and retained-storage evidence on the completed correctness-tested implementation. Separate fresh uninstrumented timing from explicitly instrumented accounting. Explain actual costs and limits rather than claiming generally bounded memory.

## Acceptance criteria

- [ ] Add deterministic bounded source workloads for all three element types: empty/small arrays, spare-capacity append, repeated class transitions, reserve/no-op reserve, ordered removal and multiple arrays reusing displaced payloads. Check live contents independently and demonstrate geometric rather than quadratic append-heavy growth.
- [ ] Report logical length, acquired element/byte capacity, active/free payload storage, allocator physical records, retained array authority metadata/descriptors, bump consumption, pages and emitted module sizes separately. Distinguish current/peak/cumulative quantities and acquired extent from logical live bytes.
- [ ] Use private explicit observation/instrumentation only; no production options, management/measurement exports or always-on counters. Verify instrumentation preserves the relevant noninstrumented calls/memory behavior and measure guest timing only on fresh uninstrumented modules/instances.
- [ ] Record exact workload/harness/source/module hashes, tool/OS/CPU versions, revision plus working-tree state, exact commands, complete raw results and repeated comparable timing samples. Run measurement modes sequentially without competing builds/benchmarks and verify sources remain stable.
- [ ] Demonstrate payload reuse and explain exact-class stranded capacity, registry lookup cost and retained descriptor/authority/unreachable-array/failed-construction storage. Stable page count alone is not a storage plateau; no GC, page return or universal memory-bound claim.
- [ ] Create a scoped M4 evidence README with observation definitions, reproduction commands, independent expected outcomes and limitations. Do not relabel historical typed-array #37 measurements as current M4 resizable-array evidence or overwrite existing records.
